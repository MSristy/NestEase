\begin{abstract}
NestEase is a unified home solutions platform designed to streamline property management, service provision, and user interactions. The system leverages a modern web stack, including a NestJS backend (MySQL, TypeORM, JWT, Stripe) and a Next.js frontend (Tailwind CSS, Radix UI), to deliver a robust, scalable, and user-friendly experience. This paper details the system architecture, design decisions, implementation, and key features such as role-based access, real-time notifications, and secure transactions.
\end{abstract}

\section{Introduction}
The real estate and home services market is fragmented, with users often needing to juggle multiple platforms for property rental, purchase, service booking, and communication. \textbf{NestEase} aims to unify these experiences, providing a single platform for landlords, tenants, buyers, sellers, and service providers.

\subsection{Backend: Role Guard Example}
\begin{lstlisting}[language=TypeScript, caption=RolesGuard Implementation]
@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const roles = this.reflector.get<string[]>('roles', context.getHandler());
    if (!roles) return true;
    const request = context.switchToHttp().getRequest();
    const user = request.user;
    const userRole = user?.role?.toLowerCase();
    const requiredRoles = roles.map(role => role.toLowerCase());
    // Role aliasing logic...
    return requiredRoles.includes(userRole);
  }
}
\end{lstlisting}

export async function apiFetch(url: string, options: RequestInit = {}) {
  const token = typeof window !== 'undefined' ? localStorage.getItem('token') : null;
  return fetch(url, {
    ...options,
    headers: {
      ...(options.headers || {}),
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
    },
  });
}
\end{lstlisting}
